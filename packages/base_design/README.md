# base_design

The hand-drawn minimal design system (from Burrow) for every app on the platform: tokens, the five handwriting voices, the seeded wobble, 35 doodles and the components. Rules and the component table: [`design/THEME.md`](../../design/THEME.md). Tokens are generated from `design/tokens.json` and `design/doodles.json`; do not edit `lib/src/generated/`.
